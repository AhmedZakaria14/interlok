# Interlock paving website

Arabic RTL Next.js website.

## Run

```sh
npm ci
npm run dev
npm run lint
npm run build
```

Set `APP_URL` to the verified public HTTPS origin before production deployment. The previous unrelated real-estate domain has been removed. Without an origin, sitemap entries and absolute social image metadata are deliberately omitted.
